# 04-数据来源与隐私保护说明.md


## 1. 数据来源

### 1.1 数据类型

本系统使用的数据均为教学场景模拟测试数据，非真实学校数据。

| 数据类型 | 数据量 | 说明 |
| :--- | :--- | :--- |
| 学生信息 | 120 名学生 | 12 个班级，每班 10 人 |
| 成绩数据 | 2880 条记录 | 120 人 × 3 学期 × 8 科目 |
| 教师评价 | 60 条 | 20 名学生 × 3 位教师 |

### 1.2 数据生成方式

所有数据通过 Python 脚本和 MySQL 存储过程自动生成：
- 学生姓名：采用 学生_1 至 学生_120 的编号格式，无真实姓名
- 成绩分数：随机生成 60-100 分范围，服从正态分布
- 评价文本：基于 20 个关键词组合生成的示例文本
- 日期字段：模拟 2024-2025 学年时间线

### 1.3 数据分布

| 年级 | 班级数 | 学生数 | 成绩记录数 |
| :--- | :--- | :--- | :--- |
| 高一 | 4 | 40 | 960 |
| 高二 | 4 | 40 | 960 |
| 高三 | 4 | 40 | 960 |
| 合计 | 12 | 120 | 2880 |

## 2. 隐私保护说明

### 2.1 无真实个人信息

- 所有姓名均为自动生成的编号（学生_1 ~ 学生_120）
- 无真实身份证号、电话号码、家庭住址等敏感信息
- 无真实教师姓名（教师使用姓氏 + 老师格式）
- 无真实学校名称

### 2.2 数据脱敏措施

| 保护措施 | 说明 |
| :--- | :--- |
| 姓名脱敏 | 学生姓名统一为 学生_编号 格式 |
| 无关联信息 | 不包含任何可追溯至真实个人的信息 |
| 仅存测试环境 | 数据仅存在于本地测试数据库，不对外公开 |

### 2.3 数据隔离

- 测试数据与生产环境完全隔离
- 使用独立的测试数据库 dify_test_v2
- 不包含任何真实业务数据

## 3. 评分机制说明

### 3.1 成绩评分

成绩表的 score 字段存储学生的考试分数：
- 范围：0-100 分
- 类型：DECIMAL(5,2)，保留两位小数
- 含义：分数越高代表成绩越好

### 3.2 教师评分（rating 字段）

评价表中的 rating 字段存储学生对教师的评分：

| 评分 | 含义 |
| :--- | :--- |
| 5 星 | 非常满意 |
| 4 星 | 满意 |
| 3 星 | 一般 |
| 2 星 | 不满意 |
| 1 星 | 非常不满意 |

## 4. 数据使用声明

- 本系统仅用于技术演示和参赛展示
- 所有数据均为模拟数据，不代表任何真实学校情况
- 如需使用真实数据，需获得数据所有方授权并进行脱敏处理
