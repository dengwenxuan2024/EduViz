# 01-项目背景与场景痛点

## 1. 为什么做这个？

### 现实问题

在中小学校和培训机构中，学生成绩数据的分析普遍面临以下困境：

- **数据分散**：成绩数据存储在教务系统的数据库中，但缺乏便捷的查询和分析工具
- **技术门槛高**：班主任、年级主任等教育工作者虽然最了解教学情况，但大多不具备SQL或数据分析技能
- **效率低下**：想要获取一个简单的分析结果（如“各班平均分排名”），通常需要向信息技术部门提需求，等待数小时甚至数天
- **分析维度单一**：传统的成绩查询只能看到“分数”，缺乏多维度、多角度的综合分析能力

### 典型场景

一名班主任想了解：
- 自己班级在年级中的位置
- 各科目的优势与薄弱环节
- 学生成绩的分布和变化趋势

但这些需求在传统模式下，要么无法满足，要么需要复杂的流程才能实现。


## 2. 目标用户

| 用户角色 | 特征 | 核心需求 |
| :--- | :--- | :--- |
| **班主任** | 关注班级整体成绩和学生个体表现 | 快速了解班级排名、各科优劣、学生分布 |
| **年级主任** | 关注年级整体水平和班级间差异 | 跨班对比、年级趋势、教学决策支持 |
| **教务人员** | 负责成绩管理和教学评估 | 生成各类分析报告、发现教学问题 |
| **学校管理者** | 关注整体教学质量和改进方向 | 宏观趋势、数据驱动的管理决策 |

## 3. 解决什么痛点？

### 痛点一：技术门槛高

**之前**：想查“高二(3)班数学平均分”，需要会写SQL或求助于技术人员。

**现在**：直接用自然语言提问——“高二(3)班数学平均分是多少？”，系统自动完成SQL生成、执行和结果返回。

### 痛点二：分析效率低

**之前**：手工整理Excel表格，做对比分析需要数小时。

**现在**：输入问题后数秒内获得完整的文字分析 + 可视化图表。

### 痛点三：分析维度单一

**之前**：只能看到分数，缺乏多维度分析。

**现在**：支持以下全部分析维度：
- 类别对比分析（柱状图）—— 班级排名、科目对比、年级对比
- 长标签类别对比（条形图）—— 类别名称较长时的水平对比展示
- 时间趋势分析（折线图）—— 各学期成绩变化趋势
- 累积趋势分析（面积图）—— 时间趋势 + 累积量展示
- 占比分布分析（饼图）—— 成绩分段占比、各维度比例
- 多维度综合对比（雷达图）—— 各科能力画像、多指标综合评估
- 成绩分布形态（箱线图）—— 五数概括、离散程度、离群点识别
- 成绩分布密度（小提琴图）—— 比箱线图更丰富的分布形态展示
- 两变量相关性（散点图）—— 数学与物理成绩关系、变量间关联分析
- 频数分布分析（直方图）—— 各分数段人数、数据集中趋势
- 累积变化构成（瀑布图）—— 各学期成绩累积变化、增减构成
- 文本评价分析（词云图）—— 教师评价关键词、高频词提取

### 痛点四：数据驱动决策缺位

**之前**：教学决策主要依赖经验和感觉。

**现在**：基于数据的客观分析，支撑精准教学决策。


## 4. 项目定位

**EduQuery** 是一个基于 Dify Agent 的智能教学数据分析助手，让教育工作者通过自然语言对话，即可完成从数据查询到分析决策的全流程。
