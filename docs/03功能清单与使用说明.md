# 03-功能清单与使用说明.md


## 1. 支持的所有查询类型

本系统支持以下 12 种分析维度，覆盖成绩分析和教学评价两大场景：

| 分析维度 | 图表类型 | 典型问题 |
| :--- | :--- | :--- |
| 类别对比 | 柱状图 | 高一年级各班平均分排名 |
| 长标签类别对比 | 条形图 | 各科目平均分对比 |
| 时间趋势 | 折线图 | 各学期成绩变化趋势 |
| 时间趋势 + 累积量 | 面积图 | 各学期累积成绩变化 |
| 占比分布 | 饼图 | 成绩分段占比 |
| 多维度综合对比 | 雷达图 | 高一(1)班各科能力画像 |
| 分布统计 | 箱线图 | 各班成绩分散程度 |
| 分布形态与密度 | 小提琴图 | 各班成绩分布形态 |
| 两变量相关性 | 散点图 | 数学与物理成绩相关性 |
| 频数分布 | 直方图 | 各分数段人数分布 |
| 累积变化构成 | 瀑布图 | 各学期成绩累积变化 |
| 文本评价分析 | 词云图 | 张老师的评价关键词 |

## 2. 示例问题

以下是 5 个代表性测试问题，涵盖系统主要功能：

### 示例1：班级排名分析
问题：高一年级各班级的平均分排名是多少？
预期输出：文字分析 + 柱状图

### 示例2：学期趋势分析
问题：高二年级各学期的成绩变化趋势如何？
预期输出：文字分析 + 折线图

### 示例3：个人成绩分析
问题：学生_1的各科成绩怎么样？
预期输出：文字分析 + 雷达图（各科能力画像）

### 示例4：成绩分布分析
问题：分析高一各班成绩的分布情况
预期输出：文字分析 + 箱线图或小提琴图

### 示例5：教师评价分析
问题：张老师的评价有哪些高频关键词？
预期输出：文字分析 + 词云图

## 3. 如何启动和使用

### 3.1 环境准备

| 依赖项 | 版本要求 | 说明 |
| :--- | :--- | :--- |
| Dify | 1.16.0 或以上 | 社区版/企业版均可 |
| MySQL | 8.0 或以上 | 数据存储 |
| Docker | 推荐 | 一键部署 |

### 3.2 部署步骤

1. 启动 Dify
   cd dify/docker
   docker-compose up -d

2. 导入数据库
   mysql -u root -p dify_test_v2 < database/schema.sql
   mysql -u root -p dify_test_v2 < database/sample_data.sql

3. 导入 Agent 配置
   - 进入 Dify 工作室
   - 点击「导入 DSL」
   - 选择 dify/agent-export.yml
   - 确认导入成功

4. 配置 Database 工具
   - 在 Agent 的「工具」中添加 Database 工具
   - 配置连接信息：
   mysql+pymysql://用户名:密码@主机:端口/dify_test_v2

5. 添加 AntV 图表工具
   - 在 Dify 插件市场安装 antv/visualization 插件
   - 在 Agent 中启用需要的图表工具

6. 测试运行
   - 在聊天框中输入任意测试问题
   - 验证 Agent 是否正确响应

### 3.3 使用方式

用户通过自然语言直接提问，无需任何技术背景：
- 输入：在聊天框输入问题
- 输出：文字分析 + 自动生成的图表
- 交互：支持连续提问和多轮对话
