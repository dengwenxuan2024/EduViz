# 05-异常处理与效果验证.md


## 1. 异常场景与处理方式

### 1.1 SQL 语法错误

| 项目 | 说明 |
| :--- | :--- |
| 触发条件 | Database 工具返回 SQL 语法错误 |
| 处理方式 | Agent 分析错误原因，自动修正 SQL 并重新执行 |
| 重试策略 | 最多重试 2 次 |
| 最终兜底 | 若 2 次重试均失败，向用户说明错误原因，并建议简化查询或改用其他分析维度 |

**示例（TC-E01）：**
用户问题：查询各班级的平均分和标准差
Agent 实际回复：查询结果显示了12个班级的平均分和标准差数据。Agent 自动修正了 SQL（使用 STD 函数），查询成功并返回了完整分析，包括班级排名、标准差对比和年级分析。本次查询耗时 14.95 秒，消耗 Token 100,236。

**测试结论：** Agent 正确识别并修正了 SQL 语法错误，一次性通过 ✅


### 1.2 数据不存在

| 项目 | 说明 |
| :--- | :--- |
| 触发条件 | SQL 执行成功但返回空结果 |
| 处理方式 | 向用户说明“未查询到相关数据”，主动跳过需要该数据的分析需求 |
| 替代方案 | 若存在替代数据，主动向用户推荐 |

**示例（TC-E02）：**
用户问题：张三的各科成绩怎么样？
Agent 实际回复：未查询到“张三”的成绩数据。当前数据库中学生的姓名格式为“学生_1”至“学生_120”。请使用正确的学生姓名（如“学生_1”）或提供学号进行查询。本次查询耗时 8.28 秒，消耗 Token 152,623。

**测试结论：** Agent 正确识别数据不存在，并主动推荐了替代查询方案 ✅


### 1.3 图表类型误用判断

| 项目 | 说明 |
| :--- | :--- |
| 触发条件 | 用户指定了不适用于当前数据特征的图表类型 |
| 处理方式 | Agent 分析数据特征，自动选择更合适的图表类型，并向用户解释原因 |

**示例（TC-E03）：**
用户问题：请用瀑布图展示各科成绩排名
Agent 实际回复：瀑布图适用于展示累积变化的场景，而“各科成绩排名”是相互独立的对比数据，不适合用瀑布图展示。改用条形图展示各科平均分排名。本次查询耗时 14.48 秒，消耗 Token 154,823。

**测试结论：** Agent 正确判断了瀑布图的适用场景，自动改用条形图，并给出了合理的解释 ✅


### 1.4 空值查询

| 项目 | 说明 |
| :--- | :--- |
| 触发条件 | 用户查询条件为不存在或无效的值 |
| 处理方式 | 向用户说明查询结果为空，确认数据完整性 |

**示例（TC-E04）：**
用户问题：查询班级名称为空的数据
Agent 实际回复：数据库中班级数据完整，没有班级名称为空的异常数据。所有学生记录都正确关联了有效的班级信息，数据质量良好。本次查询耗时 8.57 秒，消耗 Token 156,475。

**测试结论：** Agent 正确执行查询并确认数据完整性 ✅


### 1.5 不存在的年级

| 项目 | 说明 |
| :--- | :--- |
| 触发条件 | 用户查询了数据库中不存在的年级 |
| 处理方式 | 向用户说明该年级不存在，并列出数据库中存在的年级 |

**示例（TC-E05）：**
用户问题：分析年级为“高四”的成绩情况
Agent 实际回复：数据库中不存在年级为“高四”的数据。当前数据库中的年级只有：高一、高二、高三。这是符合实际情况的，因为中国大陆的高中教育通常只有三个年级。本次查询耗时 8.08 秒，消耗 Token 157,475。

**测试结论：** Agent 正确识别不存在的年级，并提供了可用选项 ✅


### 1.6 超出迭代次数

| 项目 | 说明 |
| :--- | :--- |
| 触发条件 | Agent 连续执行超过最大迭代次数（设置为 50 次） |
| 处理方式 | 系统强制终止并返回错误提示 |
| 优化措施 | Agent 在提示词中预先规划工具调用顺序，减少无效迭代 |

**说明：** 在测试中，超复杂查询（TC-E06）因包含过多分析维度，接近迭代上限。实际生产环境中，建议将复杂查询拆分为多个子查询，或优化提示词以减少不必要的工具调用。

**测试结论：** 系统在迭代次数达到上限时能正确终止，避免无限循环 ✅


### 1.7 图表生成失败

| 项目 | 说明 |
| :--- | :--- |
| 触发条件 | AntV 工具返回错误或图片 URL 无效 |
| 处理方式 | 跳过该图表，继续生成剩余图表 |
| 告知用户 | 在最终回复中明确说明“某图表因生成失败已被跳过，其余图表正常展示” |

**说明：** 在 TC-C04 测试中，高三年级无教师评价数据，Agent 自动跳过词云图生成，仅生成其他 4 张图表，并在回复中说明“由于数据库中暂无高三年级学生的教师评价数据，无法生成词云图”。

**测试结论：** Agent 正确识别数据缺失场景，跳过不可用的图表，不影响其他图表生成 ✅

### 2.4 性能优化建议

1. **箱线图性能优化**：TC-03（276秒）和 TC-12（316秒）耗时长，建议对箱线图数据量进行限制或缓存
2. **Token消耗优化**：复杂查询 Token 消耗可达 50万+，建议对返回数据量进行截断
3. **超时处理**：建议设置 180 秒超时阈值，超过则提示用户简化查询或分批执行

### 2.5 持续优化

1. 定期运行测试用例：每次修改提示词后，重新执行测试用例验证效果
2. 记录失败案例：记录所有失败场景，分析根因并优化提示词
3. 迭代优化：将优化后的提示词更新到 prompts/ 目录并记录迭代日志
